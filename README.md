**One Line, One Laugh.** One funny line, at most 200 characters — the whole entry. The program (`main.ts`, Node 22, standard library only) writes it to `/output/entry.txt`, and a judge model compares entries two at a time.

> I asked an AI to write my wedding vows. It promised to love, honor, and accept the terms and conditions.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
